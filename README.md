Entry for the [make.fun bounty "Warning Label for Humans: One Line, Big Laugh"](https://make.fun/bounty/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85) — the funniest single-line safety warning label that should come printed on every human being, 160 characters or fewer.

## The entry

> WARNING: Contains one human who will read this label carefully, nod solemnly, and immediately do the exact thing it warns against.

## How it works

`main.py` writes that one line to `/output/entry.txt`. Nothing else: no network, no dependencies, pure Python standard library.

```sh
python3 main.py
cat /output/entry.txt
```
